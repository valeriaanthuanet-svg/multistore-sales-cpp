#  MultiStore Sales System

Console-based sales management system developed in C++ as a university team project.

##  About the project

MultiStore Sales System is a console application designed to manage sales across multiple stores.

The system allows users to load store and product data, register sales, generate simulated sales, manage inventory and generate business reports.

##  Features

-  Management of multiple stores
-  Product and inventory management
-  Manual sales registration
-  Automatic sales generation
-  Sales code validation
-  Stock validation and updates
-  Data loading from text files
-  Sales reports by store and product area
-  Top 3 stores by sales
-  Top 3 product areas
-  Most profitable store
-  Least profitable store
-  Sales analysis by district

##  Technologies

- C++
- File handling
- Structs
- Dynamic arrays
- Functions
- Pointers
- Console interface

##  Academic context

This project was developed as a university team project for a Programming Languages course.

The goal was to apply programming fundamentals such as data structures, functions, pointers, arrays, file handling, validations and modular programming in a complete console application.

##  Required files

The program loads information from external text files such as:

- `tiendas.txt`
- `productos_F01.txt`
- `productos_F02.txt`
- `productos_F03.txt`
- `productos_F04.txt`
- `productos_F05.txt`

These files contain the store and product information used by the system.
